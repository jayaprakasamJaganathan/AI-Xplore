Problem 1
---------
Consider the following one-dimensional data points:
Let X = {2, 4, 6, 8, 10}, with initial centroids: C1 = 3, C2 = 9

Perform one complete iteration of K-Means:

Step 1: Calculate distance of every point from both centroids
- Point 2: d(2,3)=1, d(2,9)=7 → Cluster 1
- Point 4: d(4,3)=1, d(4,9)=5 → Cluster 1
- Point 6: d(6,3)=3, d(6,9)=3 → Cluster 1 (tie, assign to first)
- Point 8: d(8,3)=5, d(8,9)=1 → Cluster 2
- Point 10: d(10,3)=7, d(10,9)=1 → Cluster 2

Step 2: Assign each point to nearest centroid
Cluster 1: {2, 4, 6}
Cluster 2: {8, 10}

Step 3: Calculate new centroids
C1_new = (2+4+6)/3 = 4
C2_new = (8+10)/2 = 9

Step 4: Cluster assignments after first iteration
Cluster 1: {2, 4, 6}
Cluster 2: {8, 10}

Let K=2 and initial centroids be: C1 = (1,1), C2 = (8,8)

Perform one iteration of K-Means and calculate the new centroids:

Step 1: Calculate distances
- A(1,1): d(C1)=0, d(C2)=√98≈9.9 → Cluster 1

C1_new = ((1+2+3)/3, (1+2+1)/3) = (2, 1.33)

Problem 3
---------
Given:
X = {(1,1), (2,2), (3,1), (8,8), (9,7), (8,9)}
K = 2
Initial centroids: C1 = (1,1), C2 = (8,8)

After one iteration:
Cluster assignments:
Cluster 1: {(1,1), (2,2), (3,1)}
Cluster 2: {(8,8), (9,7), (8,9)}

New centroids:
C1 = (2, 1.33)
C2 = (8.33, 8)

Within-cluster SSE:
Cluster 1: (1-2)²+(1-1.33)² + (2-2)²+(2-1.33)² + (3-2)²+(1-1.33)²
         = 1+0.11 + 0+0.44 + 1+0.11 = 2.66
Cluster 2: (8-8.33)²+(8-8)² + (9-8.33)²+(7-8)² + (8-8.33)²+(9-8)²
         = 0.11+0 + 0.44+1 + 0.11+1 = 2.66
Total SSE = 2.66 + 2.66 = 5.32

Problem 4
---------
Consider the following points:
X = {(1,1), (2,1), (4,3), (5,4)}
For K=2, initial centroids are: C1 = (1,1), C2 = (5,4)

a) Perform one complete K-Means iteration:
Distances:
- (1,1): d(C1)=0, d(C2)=5 → Cluster 1
- (2,1): d(C1)=1, d(C2)=√18≈4.24 → Cluster 1
- (4,3): d(C1)=√13≈3.61, d(C2)=√2≈1.41 → Cluster 2
- (5,4): d(C1)=5, d(C2)=0 → Cluster 2

Cluster 1: {(1,1), (2,1)}
Cluster 2: {(4,3), (5,4)}

b) Updated centroids:
C1_new = (1.5, 1)
C2_new = (4.5, 3.5)

c) Total within-cluster SSE:
Cluster 1: (1-1.5)²+(1-1)² + (2-1.5)²+(1-1)² = 0.25+0 + 0.25+0 = 0.5
Cluster 2: (4-4.5)²+(3-3.5)² + (5-4.5)²+(4-3.5)² = 0.25+0.25 + 0.25+0.25 = 1.0
Total SSE = 1.5

d) Will another iteration change cluster assignments?
New distances with C1=(1.5,1), C2=(4.5,3.5):
- (1,1): d(C1)=0.5, d(C2)=√18.5≈4.3 → Cluster 1
- (2,1): d(C1)=0.5, d(C2)=√14.5≈3.8 → Cluster 1
- (4,3): d(C1)=√10.25≈3.2, d(C2)=√0.5≈0.71 → Cluster 2
- (5,4): d(C1)=√21.25≈4.6, d(C2)=√0.5≈0.71 → Cluster 2
Assignments remain the same. Algorithm has converged.

Problem 5
---------
For a dataset, the following SSE values are obtained:
K    SSE
1    1200
2    650
3    420
4    350
5    330
6    320

Questions:
1. Which value of K would you select using the Elbow Method?
   → K=3 (the "elbow" where SSE reduction rate diminishes significantly)

2. Why would selecting K=6 simply because it has the lowest SSE be misleading?
   → SSE always decreases as K increases (each point can be its own cluster with SSE=0 at K=n). The goal is to find a balance between model complexity and fit, not minimize SSE absolutely.

3. What does the sharp reduction in SSE from K=1 to K=2 indicate?
   → The data has a strong natural division into 2 clusters. The first split captures the most significant structure in the data.

Problem 6
---------
Two different K-Means runs produce:
Run  K  SSE
A    2  250
B    3  180

A student concludes: "Run B is definitely better because its SSE is lower."
Do you agree? Justify your answer.

No, I do not agree. SSE is not directly comparable across different values of K because SSE monotonically decreases as K increases. Run B has K=3 while Run A has K=2, so Run B will naturally have lower SSE. To compare fairly, you would need to:
1. Compare runs with the same K
2. Use the Elbow Method or silhouette score
3. Consider if the additional cluster in Run B captures meaningful structure or just overfits
