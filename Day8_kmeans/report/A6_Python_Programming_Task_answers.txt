====================================================================
SOLUTION: K-Means Clustering from Scratch
====================================================================

File: code/functions_modularity.py (class KMeansFromScratch)

Major Steps:
1. **Centroid Initialization**: Randomly select K data points as initial centroids
2. **Distance Calculation**: Compute Euclidean distance from each point to each centroid
3. **Cluster Assignment**: Assign each point to the nearest centroid
4. **Centroid Update**: Recalculate centroids as the mean of assigned points
5. **Iteration**: Repeat steps 2-4 until convergence (centroids don't change) or max iterations reached
6. **Inertia Calculation**: Compute within-cluster sum of squared distances

Key Implementation Details:
- Uses NumPy for vectorized operations
- Handles empty clusters by reinitializing with random data point
- Uses np.allclose() for convergence checking
- Random state for reproducibility

Elbow Method: Generated elbow_method.png for optimal K selection

SOLUTION: Linear Discriminant Analysis (LDA) from Scratch
====================================================================

File: code/functions_modularity.py (class LDAFromScratch)

Major Steps:
1. **Compute Class Means**: Calculate mean vector for each class
2. **Overall Mean**: Calculate global mean across all samples
3. **Within-Class Scatter Matrix (Sw)**: Sum of covariance matrices within each class
   Sw = Σᵢ Σₓ∈Cᵢ (x - μᵢ)(x - μᵢ)ᵀ
4. **Between-Class Scatter Matrix (Sb)**: Weighted sum of outer products of class mean differences
   Sb = Σᵢ nᵢ (μᵢ - μ)(μᵢ - μ)ᵀ
5. **Generalized Eigenvalue Problem**: Solve Sw⁻¹Sb v = λv
   - Use pseudo-inverse (np.linalg.pinv) for numerical stability
6. **Select Discriminant Components**: Sort eigenvectors by eigenvalues (descending), select top k
7. **Projection**: Transform data X_lda = X @ W where W contains selected eigenvectors

Key Implementation Details:
- Maximum components = C-1 (where C = number of classes)
- Handles singular Sw matrix using pseudo-inverse
- Standardizes features before LDA (critical for performance)

Visualization: Generated lda_projection.png showing 2D LDA projection
