TASK 1: Create a Tensor
-----------------------
**Code:**
```python
sensor_readings = np.array([25.2, 25.5, 24.9, 26.1, 25.8])
print(f"Tensor: {sensor_readings}")
print(f"Shape: {sensor_readings.shape}")           # (5,)
print(f"ndim: {sensor_readings.ndim}")             # 1
print(f"size: {sensor_readings.size}")             # 5
```

**Output:**
- Tensor: [25.2 25.5 24.9 26.1 25.8]
- Shape: (5,)
- Number of dimensions: 1
- Number of elements: 5

**Key Concept:** A 1D tensor (vector) has shape (n,), ndim=1, size=n.

TASK 8: Reshape
---------------
**Original:** `X = np.arange(24)` → shape (24,)

| Reshape | Shape | ndim |
|---------|-------|------|
| (4, 6) | (4, 6) | 2 |
| (2, 3, 4) | (2, 3, 4) | 3 |
| (6, 4) | (6, 4) | 2 |
| (24,) | (24,) | 1 |

**Why reshape doesn't change total elements:** Reshaping only changes the view/metadata (strides, shape). The underlying data buffer remains unchanged. Total elements = product of shape dimensions must remain constant.

---

TASK 9: Reshape vs Transpose
----------------------------
**Original:** `X = np.arange(24).reshape(2, 3, 4)`

- `X.reshape(3, 2, 4)`: Reinterprets memory layout, reads row-major, fills new shape
- `X.transpose(1, 0, 2)`: Permutes axes (axis 1→0, axis 0→1, axis 2→2)

**Result:** They are NOT equal. Reshape changes shape keeping memory order; transpose permutes axes rearranging data.

TASK 10: Broadcasting
---------------------
**Code:**
```python
X = np.ones((3, 4))
b = np.array([10, 20, 30, 40])
result = X + b  # (3, 4) + (4,) → (3, 4)
```

**Broadcasting Rules:**
1. Align shapes on the right: (3, 4) and (4,)
2. Compatible if equal or one is 1
3. Missing left dimensions treated as 1
4. b treated as (1, 4) → broadcast to (3, 4)
5. Element-wise operation

TASK 13: Normalize a Tensor
---------------------------
**Code:**
```python
X = np.random.randn(100, 20, 5) * 10 + 50
sensor_mean = X.mean(axis=(0, 1), keepdims=True)  # (1, 1, 5)
sensor_std = X.std(axis=(0, 1), keepdims=True)    # (1, 1, 5)
X_normalized = (X - sensor_mean) / sensor_std
```

**Verification:** Mean ≈ 0, Std ≈ 1 for each sensor ✓

TASK 14: Flattening
-------------------
**Single Image:** (28, 28, 3) → (2352,)  [28×28×3=2352]

**Batch:** (64, 28, 28, 3) → (64, 2352)  [Keep batch dimension!]

**Why not (150528,)?** Loses batch structure, can't process samples independently, model expects (batch_size, features).

TASK 15: Concatenation
----------------------
**Code:**
```python
visual = np.random.randn(32, 128)
sensor = np.random.randn(32, 64)
combined = np.concatenate([visual, sensor], axis=1)  # (32, 192)
```

**Why feature dimension works:** Batch dimension (32) matches. Concatenation requires ALL other dimensions to match exactly. The concatenation axis is where dimensions ADD.
