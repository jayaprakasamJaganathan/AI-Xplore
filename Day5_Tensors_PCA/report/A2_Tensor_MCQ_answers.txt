Assignment 2: Tensor MCQs - Answers
===================================

1. Single RGB Image
Question: An RGB image has height 224 and width 224. Using channels-last representation, what is the tensor shape?
Answer: A. (224, 224, 3)
Explanation: Channels-last format is (height, width, channels). For RGB, channels = 3.

2. Channels-First Representation
Question: The same RGB image (224 × 224) using channels-first representation has what shape?
Answer: B. (3, 224, 224)
Explanation: Channels-first format is (channels, height, width).

3. Batch of Images
Question: Suppose we have 32 RGB images, each of size 224 × 224. Using channels-last representation, what is the tensor shape?
Answer: B. (32, 224, 224, 3)
Explanation: Batch dimension comes first in channels-last: (batch, height, width, channels).

4. What Does 32 Mean?
Question: Consider the tensor: X.shape = (32, 224, 224, 3). What does 32 most likely represent?
Answer: C. Batch size
Explanation: In standard deep learning convention, the first dimension is the batch size.

5. What Does 3 Mean?
Question: For: X.shape = (32, 224, 224, 3). What does the final dimension represent?
Answer: D. Number of color channels
Explanation: The last dimension in channels-last format represents channels (RGB = 3).

6. Tensor Rank
Question: Consider: X.shape = (32, 224, 224, 3). What is the rank/number of axes of this tensor?
Answer: B. 4
Explanation: Rank = number of dimensions = length of shape tuple = 4.

7. Batch Dimension
Question: Suppose a neural network expects input of shape: (batch_size, height, width, channels). Which of the following represents 16 RGB images of size 128 × 128?
Answer: A. (16, 128, 128, 3)
Explanation: Batch=16, height=128, width=128, channels=3 (RGB).

8. Sensor Data
Question: An industrial system records data from 10 sensors, once every second, for 60 seconds. If we store the data as: X.shape = (60, 10). What does each row represent?
Answer: B. One time instant
Explanation: Shape (60, 10) means 60 rows (time steps) × 10 columns (sensors). Each row is one time instant across all sensors.

9. Adding Multiple Machines
Question: Suppose the same 60-second experiment is performed on 100 machines. If the data is represented as: X.shape = (100, 60, 10). What do the three axes represent?
Answer: A. Machines × Time × Sensors
Explanation: First axis = 100 machines, second = 60 time steps, third = 10 sensors.

10. Text as a Tensor
Question: A sentence is converted into token IDs: [15, 42, 87, 102, 9]. What is the simplest tensor representation?
Answer: B. 1D tensor
Explanation: A sequence of token IDs is a 1D tensor (vector) of length 5.

11. Understanding the Embedding Dimension
Question: In: X.shape = (32, 100, 768). What does 768 represent?
Answer: D. Embedding dimension
Explanation: Standard transformer format: (batch, sequence_length, embedding_dim). 768 is a common embedding size (e.g., BERT-base).

12. Tensor Indexing
Question: Consider: X.shape = (32, 100, 768). What does X[0] represent?
Answer: C. The first sentence/sequence
Explanation: X[0] indexes the first dimension (batch), returning shape (100, 768) - one sequence of 100 tokens with 768-dim embeddings.

13. Tensor Slicing
Question: For: X.shape = (32, 100, 768). What would X[:, 0, :] select?
Answer: B. The first token from every sentence
Explanation: [:, 0, :] selects all batches, index 0 on the sequence dimension (second axis), all embedding dimensions.

14. Shape Compatibility
Question: Suppose: A.shape = (32, 100, 768) and B.shape = (32, 100, 768). Which operation is naturally possible element-by-element?
Answer: A. Addition
Explanation: Same shape tensors can be added element-wise directly.

15. Broadcasting
Question: Suppose: X.shape = (32, 100, 768) and b.shape = (768,). What can happen when b is added to X?
Answer: B. b can be broadcast across the first two dimensions
Explanation: Broadcasting aligns from the right: (32, 100, 768) + (768,) → b is broadcast to (1, 1, 768) then to (32, 100, 768).

16. Concatenation
Question: You have two feature tensors: A.shape = (32, 100, 128), B.shape = (32, 100, 256). You concatenate them along the feature dimension. What is the resulting shape?
Answer: A. (32, 100, 384)
Explanation: Concatenating along the last axis (features): 128 + 256 = 384. Other dimensions must match.

17. Reshaping
Question: A tensor has shape: (4, 5, 6). How many total elements does it contain?
Answer: C. 120
Explanation: Total elements = product of shape dimensions = 4 × 5 × 6 = 120.

19. Reshape vs Transpose
Question: An engineer changes a tensor from: (32, 224, 224, 3) to: (32, 3, 224, 224). Which operation is conceptually appropriate?
Answer: B. Transpose/permute axes
Explanation: This changes the order of dimensions (channels-last to channels-first), not just the shape. Requires permute/transpose, not reshape.

20. Why Does This Matter?
Question: A deep-learning model expects: (batch, channels, height, width) but the image data is stored as: (batch, height, width, channels). What is the main issue?
Answer: B. The model may interpret the dimensions incorrectly
Explanation: The model will treat height as channels, width as height, and channels as width, leading to completely wrong feature extraction.

21. Flattening
Question: An RGB image has shape: (224, 224, 3). If flattened into a 1D tensor, how many elements will it contain?
Answer: C. 150,528
Explanation: 224 × 224 × 3 = 150,528.

22. Tensor vs Matrix
Question: Which statement is most accurate?
Answer: B. A matrix is a special case of a tensor
Explanation: A matrix is a 2D tensor (rank-2). Tensors generalize to any rank (0D scalar, 1D vector, 2D matrix, 3D+, etc.).

23. Neural Network Activations
Question: A neural network processes a batch of 64 samples. Each sample produces a feature vector of length 128. What is the likely shape of the activation tensor?
Answer: C. (64, 128)
Explanation: Batch size = 64, feature dimension = 128. Shape = (batch, features).

24. Convolutional Layer
Question: A CNN receives: X.shape = (16, 3, 224, 224) and produces: Y.shape = (16, 64, 112, 112). What has most likely changed?
Answer: B. Number of channels and spatial resolution
Explanation: Channels: 3 → 64 (increased by conv filters). Spatial: 224 → 112 (halved, typical stride=2 or pooling). Batch unchanged at 16.

25. Tensor as Data Organization
Question: Why are tensors particularly useful in deep learning?
Answer: A. They provide a structured way to represent multidimensional data and enable efficient numerical operations
Explanation: Tensors enable batch processing, GPU acceleration, and automatic differentiation.

26. Rank vs Size
Question: A tensor has shape: (1000, 224, 224, 3). An engineer says: "This is a rank-1000 tensor because the first dimension is 1000." Is the statement correct?
Answer: B. No, its rank is 4; 1000 is the size of its first axis
Explanation: Rank = number of dimensions = 4. The size of the first axis is 1000.

27. Challenge
Question: Consider: X.shape = (8, 30, 12, 64). Which interpretation is most reasonable for a sequence-based engineering application?
Answer: A. 8 samples, 30 time steps, 12 sensors, 64 features per sensor
Explanation: Standard format: (batch, time, sensors, features). 8 samples/batch, 30 time steps, 12 sensors, 64 features per sensor reading.
