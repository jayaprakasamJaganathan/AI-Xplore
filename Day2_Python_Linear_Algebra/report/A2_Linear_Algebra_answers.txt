#### Question 3
Given A = [2, 5, 3, 7] and B = [4, 1, 6, 8] (both 2×2 matrices)
A = [[2, 5], [3, 7]], B = [[4, 1], [6, 8]]

Find:
- A + B
- A - B
- 2A

**Solution:**
```
A + B = [[2+4, 5+1], [3+6, 7+8]] = [[6, 6], [9, 15]]
A - B = [[2-4, 5-1], [3-6, 7-8]] = [[-2, 4], [-3, -1]]
2A    = [[4, 10], [6, 14]]
```

### Part B – Matrix Multiplication

#### Question 6
Multiply A = [1, 2, 3, 4] and B = [5, 6, 7, 8] (both 2×2)
A = [[1, 2], [3, 4]], B = [[5, 6], [7, 8]]

**Solution:**
AB = [[1×5+2×7, 1×6+2×8], [3×5+4×7, 3×6+4×8]]
   = [[5+14, 6+16], [15+28, 18+32]]
   = [[19, 22], [43, 50]]

#### Question 9
Verify whether matrix multiplication is commutative.
Compute AB and BA where A = [1, 2, 3, 4] and B = [5, 6, 7, 8]
A = [[1, 2], [3, 4]], B = [[5, 6], [7, 8]]

**Solution:**
AB = [[19, 22], [43, 50]] (from Question 6)

BA = [[5×1+6×3, 5×2+6×4], [7×1+8×3, 7×2+8×4]]
   = [[5+18, 10+24], [7+24, 14+32]]
   = [[23, 34], [31, 46]]

**Conclusion:** AB ≠ BA. Matrix multiplication is **not commutative** in general.

### Part C – Vector Operations

#### Question 10
Find the magnitude of the vector x = [3, 4]ᵀ

**Solution:**
||x|| = √(3² + 4²) = √(9 + 16) = √25 = **5**

---

#### Question 11
Find the magnitude of y = [2, 5, 6]ᵀ

### Part D – Vector Spaces and Span

#### Question 16
Determine whether the following vectors are linearly independent.
v₁ = [1, 2]ᵀ, v₂ = [2, 4]ᵀ

**Solution:**
v₂ = 2 × v₁ (v₂ is a scalar multiple of v₁)
**Answer: Linearly dependent** - one vector is a scalar multiple of the other.

---

#### Question 17
Determine whether v = [5, 7]ᵀ belongs to the span of v₁ = [1, 1]ᵀ and v₂ = [2, 1]ᵀ

**Solution:**
Solve: a[1, 1] + b[2, 1] = [5, 7]
a + 2b = 5
a + b = 7

Subtracting: b = -2, then a = 9
Check: 9[1,1] + (-2)[2,1] = [9,9] + [-4,-2] = [5,7] ✓
**Answer: Yes, v ∈ span{v₁, v₂}** (with coefficients a=9, b=-2)

---

#### Question 18
Find a basis for ℝ²

**Answer:** Standard basis: **{[1, 0]ᵀ, [0, 1]ᵀ}**
Any two linearly independent vectors in ℝ² form a basis.

#### Question 19

### Part E – Orthogonality

#### Question 21
State whether the following pairs of vectors are orthogonal.

a) [1, 0]ᵀ, [0, 1]ᵀ
**Answer: Yes** - dot product = 1×0 + 0×1 = 0

b) [3, 4]ᵀ, [4, -3]ᵀ
**Answer: Yes** - dot product = 3×4 + 4×(-3) = 12 - 12 = 0

c) [2, 5]ᵀ, [5, 2]ᵀ
**Answer: No** - dot product = 2×5 + 5×2 = 10 + 10 = 20 ≠ 0

#### Question 22
Find the cosine similarity between x = [1, 2]ᵀ and y = [3, 4]ᵀ. Interpret the result.

**Solution:**
x·y = 1×3 + 2×4 = 3 + 8 = 11
||x|| = √(1² + 2²) = √5 ≈ 2.236
||y|| = √(3² + 4²) = √25 = 5

cos θ = (x·y) / (||x|| ||y||) = 11 / (√5 × 5) = 11 / (5√5) ≈ 11/11.18 ≈ **0.984**

**Interpretation:** Cosine similarity ≈ 0.984 (close to 1) means the vectors are **very similar in direction** (small angle between them, θ ≈ 10.2°).

#### Question 23
Explain, in your own words, the difference between:
- Orthogonal vectors
- Orthonormal vectors
- A basis
- A vector space

**Answer:**

**Orthogonal vectors:** Two vectors are orthogonal if their dot product is zero (they are perpendicular, angle = 90°).

**Orthonormal vectors:** A set of vectors that are both orthogonal (pairwise dot product = 0) AND normalized (each has magnitude = 1). Orthonormal = orthogonal + unit length.

**A basis:** A set of linearly independent vectors that span a vector space. Every vector in the space can be uniquely expressed as a linear combination of basis vectors. The number of vectors in a basis = dimension of the space.

**A vector space:** A collection of vectors closed under addition and scalar multiplication, satisfying 8 axioms (associativity, commutativity, identity, inverse, distributivity, etc.). Examples: ℝⁿ, polynomial space, function space.
